# 站点更新记录：文档站在往上加教程，两个小工具也顺手改了改

写了一段时间偏科普向的文章,这篇换个类型,单纯记录一下博客和文档站最近的更新情况,算是给自己留个存档,也顺便同步一下进展。

## 文档站开始往"从零上手"方向扩展

之前文档站上的内容基本都围绕着安卓折腾这块(微G 配置、谷歌服务相关的实操指南),比较零散。最近开始往上补一个系列,方向是从零开始上手 Linux 开发环境——从最基础的发行版选择、终端和 Shell 这些概念讲起,逐步往命令行工具链、编辑器(包括后面会写到的 Neovim)这些方向延伸,整体是按照从入门到进阶的顺序在排的,不是想到哪写到哪。

这部分内容和博客的风格不太一样,写得会更正式一点、去掉了博客里习惯的那种"上一篇提到过"式的碎碎念,每一篇都尽量做到独立能看懂,同时保留 中文/英文双语版本。如果对这个方向感兴趣,可以直接去文档站首页看目录:

<LinkButton href="https://shane-docs.pages.dev/zh-cn/" target="_blank" rel="noopener noreferrer">
  查看文档站首页 →
</LinkButton>

## 两个 CLI 工具也做了一轮小修小补

`shane-new-post` 和 `shane-new-doc` 这两个 npm 小工具,之前几篇专门写过来龙去脉(参数设计、postinstall 机制这些),最近又过了一轮细节:主要是修了几个边界情况下的参数解析问题,以及非交互式终端环境下的提示信息,让脚手架在不同使用场景下的行为更一致一点。两个工具的完整文档,包括安装方式和命令说明,都在文档站的 CLI 板块里:

<LinkButton href="https://shane-docs.pages.dev/zh-cn/cli/" target="_blank" rel="noopener noreferrer">
  查看 CLI 工具文档 →
</LinkButton>

日常写文档站的新文章,基本就是靠 `shane-new-doc` 一条命令把 frontmatter 和 sidebar 排序都处理掉,省了不少重复劳动,这也是当初写这两个工具的初衷。

## 博客这边

博客这边这段时间主要还是延续之前的方向,科普向的内容为主,顺手把安卓折腾相关的几个概念(root、Bootloader、分区结构这些)按照循序渐进的顺序整理了一遍。后面应该会继续保持这个更新节奏,不定期加一些新内容,想到什么写什么,不强求频率。

> [!NOTE] 关于更新频率
> 这个博客从一开始定的调子就是"随手记录",没有固定的更新计划,想写的时候多写点,没什么可写的时候可能就空着。文档站那边因为在系统性地整理一套教程,节奏会相对规律一些。

## 小结

这篇没什么技术含量,单纯是个进度同步:文档站在往"从零上手 Linux 开发"这个方向铺内容,两个 CLI 工具做了些细节打磨,博客继续按原来的节奏更新。感兴趣文档站教程的可以关注一下后续更新,也欢迎通过 Telegram(Shane_0413)交流。
